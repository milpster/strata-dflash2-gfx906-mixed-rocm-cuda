- Seams and rules:
  - Reservation prices the write BEFORE any file is opened: `file_bytes + sidecar_bytes + file_bytes` (the published file and the writer's same-size temporary) and the index entry. Park passes `sidecar_bytes = 0`: pair sidecars are charged at CAPTURE via `note_sidecar`, never a second time. `can_capture_sidecar` gates a capture the budget cannot take (its checkpoint stays target-only).
